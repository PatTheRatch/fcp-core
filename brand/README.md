# Box Out Fantasy brand assets

Three-tier logo system. Every glyph is drawn as a path, so the SVGs have no
font dependencies and render identically everywhere.

All files are generated by `generate.py`. Edit the script, not the SVGs.

## Primary: symbol + BOX OUT

| File | Use |
| --- | --- |
| `box-out-primary.svg` | Stacked, light background. Marketing, splash, README |
| `box-out-primary-dark.svg` | Stacked, dark background |
| `box-out-primary-horizontal.svg` | Symbol beside wordmark, light. Site header, nav bar, email |
| `box-out-primary-horizontal-dark.svg` | Same, dark |

## Secondary: symbol + BOX OUT + FANTASY

| File | Use |
| --- | --- |
| `box-out-secondary.svg` | Stacked with tagline, light. When the product needs a fuller name |
| `box-out-secondary-dark.svg` | Same, dark |

## Compact: symbol only

| File | Use |
| --- | --- |
| `box-out-icon.svg` | Rounded square on the dark shell color. App icon, favicon, social avatar. Tested down to 32px |
| `box-out-mark.svg` | Ink symbol, transparent background. Sidebar, inline UI on light surfaces |
| `box-out-mark-light.svg` | Paper symbol, transparent background. Inline UI on dark surfaces |

`*.png` files are 1200px rendered previews of the SVG next to them.

## Colors

| Name | Hex |
| --- | --- |
| Ink | `#2B2D31` |
| Orange | `#F26A1B` |
| Paper | `#F7F6F3` |
| Dark background | `#0D0F12` | same as `--canvas` (dark) in `docs/design_system.md`, so dark lockups and the icon tile sit flush with the app shell |

## Rules

- The basketball is the only orange element in the symbol. Do not add a second accent.
- Keep the symbol at the same height as the wordmark's width in stacked layouts, and at 1.7x cap height in horizontal layouts. `generate.py` encodes both.
- Use the compact mark anywhere narrower than about 120px.
- The gap between the O ring and the ball is fixed at 25 units on the 1200 grid. Do not widen it; at favicon size it already reads as a thin halo.

## In the app

The site's favicon is `box-out-icon.svg`, copied to `app/api/static/favicon.svg`,
with a 180px PNG render beside it as `apple-touch-icon.png`. Every page declares
both in its `<head>`, and `/favicon.ico` redirects to the SVG. After changing the
icon, copy it over and re-render the PNG.

## Regenerating

```sh
python3 generate.py
chrome --headless --no-sandbox --hide-scrollbars --window-size=1200,1200 \
  --screenshot=box-out-primary.png file://$PWD/box-out-primary.svg
```
