Tools that read for you

one token, shown once

A token lets a tool — the co-manager in Claude, say — read the same pages you read, and nothing more: your leagues, your teams' plans, the numbers behind them. It can add nobody, drop nobody and bid on nobody. Copy it when it appears; it is not shown again. Revoke one here and it stops working at once.

A token you made yourself is one you paste into a config file. One marked via OAuth was asked for by an app you allowed — you signed in, read what it wanted and pressed Allow — and it is named after that app. Both are the same kind of token, read the same pages, and are ended the same way: here.
