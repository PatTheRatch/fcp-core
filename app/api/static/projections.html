How to upload one

three ways
The file it wants, and where to send it

A CSV, .xlsx or .xls with one row per player and a column for each of the nine (with the made and attempted behind the two percentages), per game or season totals: the importer measures which. Preview first: it reports how it read each column and which names it could not match, and stores nothing.

In the browser: the upload form is the API's own page, /docs, under projections. Try POST /projections/sets/preview with your file and the season, read what it says, then the same with POST /projections/sets and a name to keep it.

From a terminal: python scripts/upload_projections.py --season 2027 --file FILE --name "…" previews it, and the same with --commit keeps it. docs/projection_sources.md has the columns it understands and how to force one it guesses wrong.
